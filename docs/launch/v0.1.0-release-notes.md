# VectorLedger v0.1.0

The first public release of VectorLedger: a vendor-neutral consistency controller for
proving that document updates, permission revocations, and deletions have propagated
across RAG data stores.

## Included

- Immutable document and chunk lineage in PostgreSQL
- Idempotent deletion and permission-revocation workflows
- Anti-entropy reconciliation and proof queries
- Signed, independently verifiable deletion receipts
- Adapters for PostgreSQL, Qdrant, and Redis
- Python SDK, CLI, REST API, and LangChain ingestion example
- Docker Compose demonstration with intentional stale-data injection
- CI, tests, issue forms, contributor templates, roadmap, and launch assets

## Run it

```bash
docker pull ghcr.io/mrhello291/vectorledger:0.1.0
docker compose up --build -d
./scripts/demo.sh
```

See the [README](https://github.com/mrhello291/VectorLedger#readme) for the architecture,
threat model, and five-minute walkthrough.
